# Project directory

A map of my repositories, grouped by what they explore. Start with the featured applications or the [42 Common Core hub](https://github.com/Rspinelli93/42-Common-Core), then browse focused exercises by topic.

Small exercises and unfinished starters are labelled as such. Repository presence does not imply deployment, production readiness, or an official 42 grade.

## 42 · Systems and algorithms

| Repository | What it explores |
| --- | --- |
| [C++ Modules · 00–09](https://github.com/Rspinelli93/CPP-Piscine) | A collection of 42 C++ exercises covering the transition from C to object-oriented programming, then exceptions, casts, templates, containers, and algorithms. Each exercise builds independently. |
| [Minishell](https://github.com/Rspinelli93/Minishell) | A collaborative Unix shell written in C by rspinell and xiribar. It combines tokenization, expansion, parsing, and execution with built-ins, pipelines, redirections, heredocs, and signal handling. |
| [ft_printf](https://github.com/Rspinelli93/ft_printf) | A C implementation of formatted output using variadic arguments. The library writes characters, strings, signed and unsigned integers, pointer addresses, hexadecimal values, and literal percent signs. |
| [Get Next Line](https://github.com/Rspinelli93/get-next-line) | A C function that reads a file descriptor one line at a time. A static buffer carries unread data between calls, while each returned line is allocated for the caller. |
| [Libft](https://github.com/Rspinelli93/libft) | A reusable C library built as the first project of the 42 Common Core. It implements character, string, memory, conversion, output, and linked-list utilities that can be linked into later C projects. |
| [miniRT](https://github.com/Rspinelli93/miniRT) | A collaborative ray tracer written in C by glucken and rspinell. It parses scene files and renders spheres, planes, cylinders, and cones with ambient, diffuse, and specular lighting and shadows. |
| [Minitalk](https://github.com/Rspinelli93/minitalk) | A pair of C programs that exchange a text message through Unix signals. The server prints its process ID; the client sends the message to that PID using SIGUSR1 and SIGUSR2. |
| [Philosophers](https://github.com/Rspinelli93/philosophers) | A simulation of the Dining Philosophers problem using POSIX threads and mutexes. It coordinates fork access, tracks meal timing, monitors starvation, and supports an optional meal-count stopping condition. |
| [Push Swap](https://github.com/Rspinelli93/push_swap) | An integer-sorting program that emits operations for two stacks. The implementation uses target selection and rotation costs to choose moves, with dedicated handling for small stacks. |
| [So Long](https://github.com/Rspinelli93/so_long) | A tile-based 2D game written in C with MiniLibX. It validates a .ber map, renders sprites, handles movement and collisions, and lets the player collect items before reaching the exit. |
| [Webserv](https://github.com/Rspinelli93/webserv) | A collaborative HTTP/1.1 server written in C++98 by glucken and rspinell. It parses server and location configuration, multiplexes client connections, serves static files, handles uploads and deletion, and executes CGI programs. |
