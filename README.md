I’m Riccardo, also known as Richard, studying at École 42 Lausanne. My work focuses on understanding software from the inside out: memory, processes, algorithms, Unix systems, networking, and graphics.

Before 42, I studied web development at The Bridge and built projects with React, Node.js, Express, MongoDB, and SQL. This profile follows that path from small browser exercises to collaborative systems projects.
